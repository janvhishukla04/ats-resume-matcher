# ATS Resume Matcher

Upload your resume + paste a job description → get an ATS match score and missing keywords instantly.

🔗 **[Live Demo](https://ats-resume-matcher-popt.onrender.com)**

---

## What It Does

- Upload your resume (PDF) + paste any job description
- Get a **match score (0–100%)** using TF-IDF + cosine similarity
- See which **keywords are missing** from your resume
- Every check saved to a database to track improvement over time

## Tech Stack

`FastAPI` `scikit-learn` `SQLAlchemy` `pypdf` `SQLite` `Render`
